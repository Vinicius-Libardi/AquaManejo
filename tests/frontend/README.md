# Testes do frontend

`frontend-structure.test.js` verifica a estrutura das sete telas, atributos dos formulários, navegação, escape de conteúdo, funções dos gráficos, responsividade e informações acessíveis. Execute pela raiz com `npm test`.

Os testes de canvas usam um contexto simulado do Node. Eles não substituem uma revisão visual em navegadores reais.

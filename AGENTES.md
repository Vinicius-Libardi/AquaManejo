# Projeto AquaManejo

## Objetivo
Desenvolver um aplicativo web para produtores aquícolas acompanharem a qualidade da água de seus viveiros.

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- SQLite
- Chart.js

## Idioma
Toda a interface deve estar em português brasileiro.

## Organização
Manter frontend e backend separados.
Utilizar código organizado, modular e de fácil manutenção.

## Regras de desenvolvimento
1. Não criar funcionalidades que não foram solicitadas.
2. Não excluir funcionalidades existentes sem autorização.
3. Explicar as alterações realizadas.
4. Priorizar soluções simples e adequadas para iniciantes.
5. Comentar trechos de código quando isso ajudar no aprendizado.
6. Validar os dados recebidos pelo backend.
7. Nunca armazenar senhas ou segredos diretamente no código.
8. Não utilizar dados fictícios como se fossem referências técnicas reais.
9. Criar testes para as funcionalidades principais.
10. Antes de alterar a arquitetura, explicar a necessidade.

## Qualidade da água
As classificações devem considerar a espécie cultivada, a fase de desenvolvimento e as condições do cultivo.
Os limites técnicos devem ser configuráveis e possuir fontes de referência.
Não inventar limites técnicos.
Distinguir situações adequadas, de atenção e críticas.
